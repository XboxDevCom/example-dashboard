# Example: Dashboard

A dashboard/settings hub example running with UWP technology on the Xbox One, demonstrating SplitView menu navigation and multi-page Frame navigation.

## Getting Started

Please follow our [tutorial](https://xboxdev.com/tutorials) to create your own Dashboard application for the Xbox One.

## Built with

* [Visual Studio](https://visualstudio.microsoft.com/) - C# Editor from Microsoft
* [Xbox One](https://afflnk.microsoft.com/c/1256010/476314/7806/) - Testing the application
* [Microsoft.NETCore.UniversalWindowsPlatform](https://www.nuget.org/packages/Microsoft.NETCore.UniversalWindowsPlatform/) - UWP framework

## Features

* SplitView navigation with menu items
* Multi-page Frame navigation
* Settings controls (ToggleSwitch, Slider, ComboBox)
* Xbox gamepad menu navigation with XYFocus
* ElementSoundPlayer for UI sounds
